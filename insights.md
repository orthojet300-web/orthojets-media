## What works / what doesn't
- **Symptom-scenario hook + can't-miss emergency wins**: "Back pain + numb saddle + bladder change: cauda equina?" got 346
  TikTok views (others 115–148). It speaks to every ED/GP/neuro viewer, not only orthopods, and opens with what the
  patient presents with, not the name of a classification.
- **Classification-first episodes are the weakest** (Salter-Harris 115, Gustilo 132 on TikTok). Paediatric-niche topics
  (Kocher, Salter-Harris) under-perform; adult ED emergencies do better.
- Hard numbers with a time window ("reduce within 6 hours, AVN 4.8% vs 52.9%") get the most likes per view.
- **The hook is still the #1 problem on Instagram**: avg watch 1.3–3.6 s on ~60 s reels, only 3–12% of views pass 3 s.
  Scaphoid (opens with a statistic) held worst.
- A/B quick-choice questions (EP07 on) still gave 0 real comments — keep them but don't expect comments yet.
- Music track and background theme: no visible effect (all within the same 115–148 band except cauda equina).

## Guidance for the next episodes
- Open with the patient in one line (age/mechanism + the alarming sign) and the question, e.g. "Snap at the heel, still
  walking: Achilles rupture?" Name the eponym/classification only after that. Same line = first caption line + TikTok title.
- First 1–2 s must show movement + the key visual (the X-ray/diagram), not a title card.
- Prefer adult ED emergencies and "do I image / operate / call now?" decisions; frame classifications around the one
  decision they change ("Garden: fix or replace?"), and keep them spaced out.
- Queue reordered 2026-11-01 (series rotation kept, no topic removed): Achilles → Canadian C-spine → Lisfranc → Garden →
  Mirels → Ottawa knee → Klein's line → Schatzker → Kanavel → Cobb → Weber → DDH → Neer.
